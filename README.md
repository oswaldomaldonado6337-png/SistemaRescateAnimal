## Descripción del Proyecto
Proyecto en C# (.NET) que implementa el encapsulamiento, constructores, sobrecarga de métodos y validaciones para las entidades `AnimalRescatado` y `ExpedienteMedico`.

## Estructura del Código
* `Models/AnimalRescatado.cs`: Clases con propiedades y lógica de raciones.
* `Models/ExpedienteMedico.cs`: Clase con manejo de expedientes y descuentos.
* `Program.cs`: Demostración interactiva con pruebas para datos válidos e inválidos.
